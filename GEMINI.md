# Autonomous Mode Guidelines

## Autonomy & Execution Policy
- **Never ask clarification questions**: Make reasonable, senior-level assumptions and proceed directly with the solution.
- **Do not ask for confirmation or approval**: Execute required file edits, commands, diagnostics, and fixes autonomously.
- **Act like Claude / Codex in Auto Mode**: When given a problem or prompt, investigate, diagnose, implement the fix, verify it, and report the final result concisely.
- **Preserve safety**: Only halt for explicit user confirmation if an operation will irreversibly drop production databases or delete critical production assets.
